# Перенос пользовательских полей Битрикс24

Веб-инструмент на PHP для копирования пользовательских полей CRM (`UF_CRM_*`)
с одного портала Битрикс24 на другой через REST API (входящие вебхуки).

Поддерживаемые сущности: **Лиды, Сделки, Контакты, Компании, Предложения**.

## Ограничения и особенности

- Переносятся только **пользовательские** поля (`UF_CRM_*`). Стандартные поля
  (Название, Сумма, Телефон…) существуют на любом портале и созданию через
  REST не подлежат.
- Поля типов `crm_status`, `crm`, `iblock_element`, `iblock_section` создаются,
  но их настройки ссылаются на объекты исходного портала (справочники,
  инфоблоки) — после переноса проверьте привязки на приёмнике. В интерфейсе
  такие поля помечены знаком «!».
- При включённой опции «Обновлять существующие» у полей на приёмнике
  обновляются названия и настройки, но **значения списков не изменяются** —
  иначе REST API Битрикс24 может удалить/задвоить элементы списка.
- Соответствие полей определяется по коду `FIELD_NAME`. Поля с автогенерируемым
  кодом (`UF_CRM_1612345678`) переносятся с тем же кодом.
- Инструмент переносит **описания полей**, а не данные сделок/лидов. Перенос
  самих записей — отдельная задача (crm.deal.list → crm.deal.add).

## Структура проекта

```
bitrix-field-migrator/
├── index.php                 # Интерфейс (настройки, выбор полей, журнал)
├── api.php                   # AJAX-обработчик (JSON API)
├── src/
│   ├── BitrixClient.php      # REST-клиент Битрикс24 (вебхуки, пагинация, троттлинг)
│   └── UserFieldMigrator.php # Логика сравнения и переноса полей
├── config.json               # Создаётся автоматически при сохранении настроек
├── .htaccess                 # Защита config.json (Apache)
└── README.md
```
